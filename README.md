# ЕГЭ тренажёр

Браузерный тренажёр для подготовки к заданиям ЕГЭ по русскому языку.

## Задания

| Задание | Описание | Файл данных |
|---------|----------|-------------|
| **Задание 4** | Ударения в словах | `data_4.txt` |
| **Задание 9** | Гласные в словарных словах | `check_spell_data.txt` |
| **Задание 10** | Приставки ПРЕ/ПРИ | `data_10.txt` |

## Запуск

Просто откройте `index.html` в браузере. Для загрузки словарей через `fetch()` нужен HTTP-сервер:

```bash
# Python
python -m http.server 8000

# Node.js
npx serve .

# PHP
php -S localhost:8000
```

Затем откройте `http://localhost:8000`.

## Режимы игры

- **Быстрый** — 20 слов
- **Средний** — 50 слов
- **Полный** — все слова из словаря

## Возможности

- Три режима тренировки на выбор
- Отработка ошибок — слова с ошибками сохраняются и доступны для повторной тренировки
- Тёмная и светлая тема
- Предупреждение при вводе в английской раскладке (задание 9)
- Адаптивный дизайн для мобильных устройств
- Прогресс-бар и статистика в реальном времени

## Хранение ошибок

Ошибки сохраняются в `localStorage` под ключами:

| Ключ | Задание |
|------|---------|
| `task4Errors` | Ударения |
| `task9Errors` | Словарные слова |
| `task10Errors` | ПРЕ/ПРИ |

Каждая запись содержит слово, правильный ответ, ответ пользователя, временную метку и счётчик ошибок.

## Структура файлов

```
├── index.html          # Главная страница с HTML-разметкой
├── style.css           # Стили с CSS-переменными для тем
├── js/
│   ├── shared.js       # Общие функции (тема, навигация)
│   ├── task4.js        # Логика задания 4 (ударения)
│   ├── task9.js        # Логика задания 9 (словарные слова)
│   └── task10.js       # Логика задания 10 (ПРЕ/ПРИ)
├── check_spell_data.txt # Словарь для задания 9
├── data_4.txt          # Словарь для задания 4
├── data_10.txt         # Словарь для задания 10
└── data.txt            # Сырой список слов (не используется)
```

## Формат файлов данных

### Задание 9 (`check_spell_data.txt`)
```
абитуриент=аб_туриент
орбита=_рбита (🪐)
```

### Задание 10 (`data_10.txt`)
```
преувеличить=пр_увеличить (размер)
приехать=пр_ехать (в город)
```

### Задание 4 (`data_4.txt`)
```
звонИт
тОрты
красивЕе
```

## Технологии

Чистый HTML, CSS и JavaScript — без фреймворков и зависимостей.
